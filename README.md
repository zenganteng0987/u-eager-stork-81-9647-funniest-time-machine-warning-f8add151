# u-eager-stork-81-9647-funniest-time-machine-warning-f8add151

Funniest Time Machine Warning Label — a one-line warning label for a time machine, 120 characters or fewer.

## Entry

> WARNING: If you encounter yourself, do not panic. Only one of you is real, and it is not the one reading this.

(110 characters.)

## How it works

`main.ts` writes that single line to `/output/entry.txt` (or to `$OUTPUT_PATH` when set). No network, no dependencies.

Run it:

```sh
node main.ts
```
